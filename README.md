# Student Grade Tracker (Java)

This project is created for CodeAlpha Internship.

## Features

* Add student details
* Calculate average marks
* Highest & lowest marks
* Grade system (A, B, C, Fail)
* Total students count

## Technologies Used

* Java
* OOP (Object-Oriented Programming)
* ArrayList

## How to Run

1. Open in IntelliJ
2. Run Main.java
3. Use menu to add students and view report
